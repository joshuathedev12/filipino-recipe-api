Endpoints

All requests need your API key in the X-API-Key header.

GET /api/recipes All recipes (paginated)
GET /api/recipes/:id Single recipe by ID
GET /api/recipes/search?q=adobo Search by name or ingredient
GET /api/recipes/category/:category Filter by category (chicken, pork, …)
GET /api/recipes/random Random recipe
GET /api/categories Categories with recipe counts
POST /api/register Register for a new key

Usage

Replace YOUR_API_KEY with the key you generated above.

# Get all recipes
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes

# Get recipe by ID
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/1

# Search for adobo
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/search?q=adobo

# Chicken recipes
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/category/chicken

# Random recipe
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/random
// JavaScript (fetch)
const res = await fetch('https://api.waiscart.ai.studio/api/recipes', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
});
const data = await res.json();
console.log(data);
