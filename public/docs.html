📡 API Endpoints

All endpoints require your API key in the X-API-Key header.

GET /api/recipes List all recipes (paginated)
GET /api/recipes/:id Get a single recipe by ID
GET /api/recipes/search?q=adobo Search recipes by name or ingredient
GET /api/recipes/category/:category Filter by category (e.g., "chicken", "pork")
GET /api/recipes/random Get a random recipe
GET /api/categories Get all categories with recipe counts
POST /api/register Register for a new API key

💻 Example Usage

Try these commands with your API key (replace YOUR_API_KEY).

curl

# Get all recipes
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes

# Get recipe by ID
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/1

# Search for Adobo
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/search?q=adobo

# Chicken recipes
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/category/chicken

# Random recipe
curl -H "X-API-Key: YOUR_API_KEY" https://api.waiscart.ai.studio/api/recipes/random

JavaScript (fetch)

const response = await fetch('https://api.waiscart.ai.studio/api/recipes', {
  headers: {
    'X-API-Key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
console.log(data);
